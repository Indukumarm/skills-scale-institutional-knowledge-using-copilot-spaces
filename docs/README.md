# OctoAcme Project Management Docs

Welcome! This directory provides all core process documentation for managing projects with the OctoAcme approach.

## Project Management Process Summary

OctoAcme emphasizes customer-centric, iterative delivery using clear ownership, actionable artifacts, and regular communication. The lifecycle covers initiation (problem, stakeholders, timeline), planning (scope, backlog, risks), execution (standups, reviews, QA), release, and continuous improvement via retrospectives. Roles and artifacts are defined to ensure transparency, accountability, and continuous learning.
